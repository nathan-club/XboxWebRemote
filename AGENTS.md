# Public repository guidance

- Keep source, examples, documentation, commit messages, and pull requests generic.
- Do not publish personal deployment plans, locations, network topology, internal addresses,
  hostnames, account details, credentials, local filesystem paths, or operational logs.
- Use reserved example domains and synthetic test values in public examples.
- Keep environment-specific deployment notes outside this repository.
- Before pushing, inspect the staged diff and commit author/committer identity for privacy.
- Use a privacy-preserving commit identity; do not inherit a workstation's personal identity.
